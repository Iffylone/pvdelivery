MercadoPago — Checkout API
SDK oficial v2 · Sandbox gratuito · Tarjetas, QR, billeteras
NO CONFIG
🚀 SETUP SANDBOX (sin dinero real):
1. Creá cuenta en mercadopago.com.ar/developers
2. Panel → Tus integraciones → Crear aplicación → tipo: Checkout API
3. En la app → Credenciales de prueba (pestaña TEST):
• Copiá Access Token → empieza con TEST-
• Copiá Public Key → empieza con TEST-
4. En Railway → Settings → Variables:
MP_ACCESS_TOKEN = TEST-xxxx-tu-token-aqui
MP_PUBLIC_KEY = TEST-xxxx-tu-public-key-aqui
5. Redeploy → npm install mercadopago se ejecuta automático

MODO (billetera bancaria)
Galicia, Santander, BBVA, Macro, HSBC, Patagonia y +30 bancos
REQUIERE ONBOARDING
📋 Proceso de integración MODO (sin sandbox público):
1. Registrate como comercio en modo.com.ar/empresas
2. MODO requiere previamente una cuenta en Payway Ventas Online (Decidir):
→ Alta en onboarding.payway.com.ar (necesitás CUIT inscripto en AFIP)
→ Te envían: Site ID, API Key Pública, API Key Privada
3. Completá el formulario MODO con esas keys → en 48hs recibís credenciales MODO
4. Variables de entorno a configurar en Railway:
MODO_CLIENT_ID · MODO_CLIENT_SECRET
✅ MIENTRAS TANTO: Los clientes con MODO pueden pagar via QR interoperable de tu CBU/CVU (ya funciona sin integración API).
MODO no tiene entorno sandbox público — las pruebas se hacen en producción con montos mínimos ($1) con sus propias cuentas reales de prueba que proveen ellos.

Personal Pay (Telecom)
Billetera de Personal/Fibertel — pago QR y transferencia
QR YA FUNCIONA
Personal Pay no tiene API pública de e-commerce.
Los usuarios de Personal Pay pueden pagarte de dos formas:
→ Transferencia por CVU/CBU: el cliente ve el CBU/Alias en el pedido y transfiere desde Personal Pay como cualquier billetera
→ QR interoperable BCRA: si tenés QR de MercadoPago o de tu banco, Personal Pay lo puede escanear (Transferencia 3.0)
✅ Ya funciona: configurá tu CBU/Alias en Config → el cliente verá el datos de transferencia al pagar.
💜
Ualá · Naranja X · BNA+ · Cuenta DNI
Todas las billeteras del ecosistema Transferencia 3.0 BCRA
CBU YA FUNCIONA
Estas billeteras pueden pagar a tu CBU/CVU/Alias o escanear el QR de MercadoPago (interoperable BCRA).
No requieren integración API adicional. Con el CBU/Alias configurado en Config, el sistema ya los soporta.

Servidor en tu PC (red local)
Instalar Node.js en tu PC:
1. Descargá Node.js de nodejs.org
2. Copiá los archivos del sistema en una carpeta
3. Abrí una terminal en esa carpeta y ejecutá:
npm install && node server.js

4. Abrí en el navegador: localhost:3000
5. Otros dispositivos en la misma WiFi usan la IP de la PC:
http://192.168.X.X:3000

Para saber tu IP: Windows → ipconfig en CMD. Buscá "IPv4".

💾 Backup de datos
Descarga un archivo con todos los datos actuales del sistema (pedidos, productos, clientes, empleados, repartidores, configuración del negocio). Nunca incluye claves de acceso. Guardalo en un lugar seguro periódicamente.

Esto borra todos los pedidos, clientes, productos, empleados y repartidores, y deja el nombre/dirección/CBU del negocio en blanco — valores de fábrica.
